TEST CHAR FOR ALPHA  (EBCDIC)

To test for an alphabetic character in z390 baseless 32-bit HLASM without using 
the TRT instruction, you must evaluate the byte using sequential range checking. 
Because EBCDIC letters are broken up into three distinct blocks for 
lowercase (a-i, j-r, s-z) and three blocks for uppercase (A-I, J-R, S-Z), 
you have to check all six ranges.

Since this is baseless, we exclusively use 32-bit register operations 
and Branch Relative (BRC) instructions to avoid relying on a base register.

Implementation Example

* =====================================================================
* FUNCTION: TEST_ALPHA_NO_TRT
* INPUT:    A single EBCDIC byte stored at label 'MYCHAR'
* OUTPUT:   Condition Code (CC) set by the final evaluation,
*           branching directly to IS_ALPHA or NOT_ALPHA.
* =====================================================================
TEST_ALPHA DS    0H
           LLC   1,MYCHAR         Load Logical Character into Reg 1 (Clears upper 24 bits)
*
* --- LOWERCASE CHECK (a-i = X'81'-X'89', j-r = X'91'-X'99', s-z = X'A2'-X'A9') ---
*
           CHI   1,X'81'          Compare with 'a'
           BL    CHECK_UPPER      If lower than X'81', it can't be lowercase
           CHI   1,X'89'          Compare with 'i'
           BNH   IS_ALPHA         If between X'81' and X'89', it is alpha
*
           CHI   1,X'91'          Compare with 'j'
           BL    CHECK_UPPER      If in the gap between 'i' and 'j'
           CHI   1,X'99'          Compare with 'r'
           BNH   IS_ALPHA         If between X'91' and X'99', it is alpha
*
           CHI   1,X'A2'          Compare with 's'
           BL    CHECK_UPPER      If in the gap between 'r' and 's'
           CHI   1,X'A9'          Compare with 'z'
           BNH   IS_ALPHA         If between X'A2' and X'A9', it is alpha
*
* --- UPPERCASE CHECK (A-I = X'C1'-X'C9', J-R = X'D1'-X'D9', S-Z = X'E2'-X'E9') ---
*
CHECK_UPPER DS    0H
           CHI   1,X'C1'          Compare with 'A'
           BL    NOT_ALPHA        If lower than X'C1', it failed all checks
           CHI   1,X'C9'          Compare with 'I'
           BNH   IS_ALPHA         If between X'C1' and X'C9', it is alpha
*
           CHI   1,X'D1'          Compare with 'J'
           BL    NOT_ALPHA        If in the gap between 'I' and 'J'
           CHI   1,X'D9'          Compare with 'R'
           BNH   IS_ALPHA         If between X'D1' and X'D9', it is alpha
*
           CHI   1,X'E2'          Compare with 'S'
           BL    NOT_ALPHA        If in the gap between 'R' and 'S'
           CHI   1,X'E9'          Compare with 'Z'
           BNH   IS_ALPHA         If between X'E2' and X'E9', it is alpha
*
* --- FALLTHROUGH: NOT ALPHABETIC ---

           BRC   15,DONE          Unconditional branch to finish
*
* --- SUCCESS: IS ALPHABETIC ---
IS_ALPHA   DS    0H
*          ... Your logic for alphabetic character goes here ...
*
DONE       DS    0H
           BR    14               Return to caller

* DATA DEFINITIONS

2. The Alternative Way: Without TRT (Byte-by-Byte Loop)

If you specifically cannot use TRT, you must use a baseless pointer 
loop that loads each byte via LLC (Load Logical Character), uses 
CHI (Compare Halfword Immediate) to range-check it against alphabetic 
and numeric zones, and increments through the field.


* =====================================================================
* FUNCTION: IS_ALNUM_LOOP (No TRT)
* INPUT:    R2 = Address of the field to check
*           R3 = Length of the field
* =====================================================================

           LARL  2,MYFIELD        Load address of the field into R2 (Baseless)
           LHI   3,L'MYFIELD      Load the literal length of the field into R3
ALNUM_LOOP DS    0H
           LTR   3,3              Check if length is zero
           BRC   8,INVALID        Empty field is not alphanumeric
*
LOOP_NEXT  DS    0H
           LLC   1,0(,2)          Load 1 byte from field pointer into R1
*
* --- Check Numeric Range (0-9 = X'F0'-X'F9') ---
           CHI   1,X'F0'
           JL    CHK_LOW          If less than X'F0', check lowercase
           CHI   1,X'F9'
           JNH   CHAR_OK          If between X'F0' and X'F9', this byte is valid
*
* --- Check Lowercase Ranges ---
CHK_LOW    CHI   1,X'81'          'a'
           JL    CHK_UPP
           CHI   1,X'89'          'i'
           JNH   CHAR_OK
*
           CHI   1,X'91'          'j'
           JL    CHK_UPP
           CHI   1,X'99'          'r'
           JNH   CHAR_OK
*
           CHI   1,X'A2'          's'
           JL    CHK_UPP
           CHI   1,X'A9'          'z'
           JNH   CHAR_OK
*
* --- Check Uppercase Ranges ---
CHK_UPP    CHI   1,X'C1'          'A'
           JL    INVALID          Less than 'A' and missed numbers -> Failed
           CHI   1,X'C9'          'I'
           JNH   CHAR_OK
*
           CHI   1,X'D1'          'J'
           JL    INVALID
           CHI   1,X'D9'          'R'
           JNH   CHAR_OK
*
           CHI   1,X'E2'          'S'
           JL    INVALID
           CHI   1,X'E9'          'Z'
           JH    INVALID          Greater than 'Z' -> Failed
*
* --- Byte is Valid, Advance Pointer ---
CHAR_OK    LAY   2,1(,2)          Increment address by 1 byte
           BRCT  3,LOOP_NEXT      Decrement length in R3; loop if > 0
*
* If loop finishes successfully, the entire field is Alphanumeric
VALID      DS    0H
*          ... handle valid case ...
           BR    14
*
INVALID    DS    0H
*          ... handle invalid case ...
           BR    14
